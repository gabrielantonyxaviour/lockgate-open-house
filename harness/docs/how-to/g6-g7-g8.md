## Rebuild

From `lockgate/repo/harness`. These commands write artifacts to `contracts/out` and `harness/fixture/out`. The cache paths stay outside the repo, so the shared `contracts/cache` is not replaced. Do not `forge clean`.

```bash
mkdir -p /tmp/lockgate-g8-verify/contracts-cache /tmp/lockgate-g8-verify/fixture-cache
forge build --skip test --root ../contracts --cache-path /tmp/lockgate-g8-verify/contracts-cache
forge build --root fixture --cache-path /tmp/lockgate-g8-verify/fixture-cache
```
